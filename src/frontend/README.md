# Frontend README

React + TypeScript frontend for Open-CRM.

## Tech Stack
- React
- TypeScript
- Vite
- Mantine UI
- React Router v6

## Project Structure
```
src/
├── api/
├── assets/
├── components/
├── context/
├── pages/
└── styles/
 App.tsx
 main.tsx
```

## Getting Started

### Prerequisites
- Node.js v18+

### Install dependencies
npm install

### Run development server
npm run dev

App runs at http://localhost:5173
